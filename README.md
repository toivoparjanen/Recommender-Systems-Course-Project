# Recommender-Systems-Course-Project
Repository for DATA.ML.360 course group 8

# Setup and usage
1. Pull the repository on to your machine
2. Create a folder called data in your installation folder
3. Get the MovieLens 1M Dataset from https://grouplens.org/datasets/movielens/1m/ and unzip the file in to the data folder
4. Make sure you are on python version >= 3.12
5. Install requirements using the requirements.txt file with pip \
command: ```pip install -r ./requirements.txt```
6. Run the project with this command: ```python run_all.py```
